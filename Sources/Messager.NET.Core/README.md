# Messager.NET.Core

Contracts for typed publish/subscribe messaging, requests and queues
in [Messager.NET](https://github.com/NovoDwarf/Messager.NET).

Targets .NET 10 and .NET 11.

```sh
dotnet add package Messager.NET.Core
```

Use this package when a project only needs the messaging interfaces.
Install [Messager.NET](https://www.nuget.org/packages/Messager.NET) for the runtime implementation.

This project is under development and is not production-ready. See
the [repository](https://github.com/NovoDwarf/Messager.NET) for details.
